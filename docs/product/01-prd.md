# FactNuggets Product Requirements Document (PRD)

Version: 1.0

Status: MVP Planning

---

# 1. Executive Summary

FactNuggets is a curiosity-driven learning platform designed for children aged 5–8.

The product transforms screen time into meaningful discovery by replacing random, unstructured digital consumption with curated educational learning cards.

Children explore themed learning packs containing interesting facts, images, and explanations.

Parents receive confidence that their child's digital activity is safe, intentional, and educational.

---

# 2. Product Overview

## Product Name

FactNuggets

## Product Category

Children's educational discovery platform.

## Core Experience

Discover → Learn → Collect → Unlock → Explore

---

# 3. Goals

## Primary Goals

### 1. Replace meaningless screen time

Help parents provide children with a safer alternative to random digital content.

---

### 2. Build curiosity habits

Encourage children to regularly discover new information about the world.

---

### 3. Create parent trust

Ensure every piece of content feels safe, accurate, and age appropriate.

---

### 4. Create a scalable content platform

Build a system where new learning packs can be continuously created.

---

# 4. Non-Goals

FactNuggets MVP will NOT:

- replace school education
- teach full curriculum subjects
- become a parental control application
- monitor all device activity
- include social features
- include child-to-child communication
- include AI chat
- include infinite content feeds

## Required

- title
- image
- short fact
- child-friendly explanation

# 10. MVP Feature Scope

---

# Feature 1: Guest Mode

Priority: P0

Description:

Children can start using FactNuggets without account creation.

Purpose:

Remove friction.

Includes:

- free content access
- local progress
- basic rewards

---

# Feature 2: Learning Pack System

Priority: P0

Description:

Organized collections of learning cards.

Example:

Ocean Pack.

Contains:

- multiple cards
- completion tracking
- reward

---

# Feature 3: Card Experience

Priority: P0

Description:

Core learning interaction.

Requirements:

- display image
- display fact
- allow swipe navigation
- mark completion

---

# Feature 4: Progress Tracking

Priority: P0

Track:

- completed packs
- completed cards
- earned rewards

---

# Feature 5: Reward System

Priority: P0
